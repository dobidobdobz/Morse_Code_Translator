Morse Code translator

Similar to how you would expect a translator app to work like google translate.
This was all built in python, tkinter graphics library.
The app will take any latin based alphabet letters and directly translates each individual letter to Morse-Code.
You can also switch around the functionality you Morse-code can be translated to latin based alphabet!
